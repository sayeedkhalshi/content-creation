### Management -

Philosophically management is the biggest problem ever on web, and the solution I want is to give people a home when they open their computer, they can call their own.

1. A home like app interface on desktop
2. Game like UI
3. Integrated with browser and blockchain wallet
4. Non random narrative based content creation on web

### Decentralization and true persistence of data

1. A micro node of blockchain ledger, contract executioner - example - micro sui integrated inside the app user can install and use the ledger without an external rpc.
2. A storage system
3. A simple dynamic consensus like mysteceti

All three packed in the desktop software.

### New thing

1. That software can render smart contract to a UI like html-css parser, js interpreter.
2. People can deploy a smart contract and that can have both frontend and backend using 'seal' like tech, each contract. Ledger as the data points and storage as the DB.

### Server

1. People can start server, attach domain all in that blockchain network and visitable/interactable inside the software.
